# Deep Learning Assignments

This repository contains nine practical assignments for a Deep Learning course. Each assignment is organized in its own folder and includes a practical sheet (`.docx`), a PDF copy, and a Jupyter notebook or notebook-format file.

## Repository navigation

| Assignment | Topic | Folder |
| --- | --- | --- |
| 1 | TensorFlow/Keras setup, KMNIST preprocessing, train/test split, and image visualization | [Assignment 1](Assignment%201/) |
| 2 | Multilayer Perceptron (MLP) classification with the Iris or Wine dataset | [Assignment 2](Assignment%202/) |
| 3 | Forward propagation and backpropagation; effect of learning rate and epochs | [Assignment 3](Assignment%203/) |
| 4 | LSTM-based time-series forecasting using sales data | [Assignment 4](Assignment%204/) |
| 5 | RNN, LSTM, and GRU comparison for sequence classification | [Assignment 5](Assignment%205/) |
| 6 | CNN image classification for tomato or soybean disease data | [Assignment 6](Assignment%206/) |
| 7 | Transfer learning with pretrained image-classification models | [Assignment 7](Assignment%207/) |
| 8 | Pretrained BERT for sentiment analysis/text classification | [Assignment 8](Assignment%208/) |
| 9 | Pretrained Vision Transformer versus CNN for Oxford-IIIT Pet breed classification | [Assignment 9](Assignment%209/) |

## Working with the notebooks

Open the `.ipynb` files in Jupyter Notebook, JupyterLab, or Google Colab. The Assignment 8 file can also be opened as a notebook; if a tool does not recognize it automatically, make a copy with an `.ipynb` extension before opening it.

The notebooks may download datasets or pretrained models and may require additional Python packages, an internet connection, and substantial compute resources. Check each notebook's setup and data-loading cells for its specific requirements. Dataset files are not listed as part of this repository's assignment folders.
